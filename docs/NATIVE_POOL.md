## Operations

`bb pool native status`, `submit KEY PROJECT INPUT [--cell ID]`, `reconcile`, and
`stop INTENT` use the same functions as the Native workers settings surface.
A submission key is immutable: reusing it with different input is rejected.
Initial input is removed locally only when the exact queued response ID commits.
Ambiguous sends remain unknown; neither restart nor reconcile resends them.
Stop records cancellation before asynchronous work settles; cancellation remains
held until retry resurrection has been separately qualified. It never frees a
slot from the Stop acknowledgement alone.

`bb pool native enroll JSON` validates an existing BB host and requires its
central-pooling exclusion before persisting a disabled/unqualified cell. JSON
fields are id, hostId, generation, label, workspace and sshTarget.
`bb pool native configure JSON` persists controller policy (no cellId) or cell
flags (cellId supplied). It accepts enabled, qualified, and the explicit
qualification assertion `installed-worker-verified`. Enabling requires qualified;
qualification requires that exact operator assertion. This assertion records an
operator decision; it is not automatic evidence of live acceptance. No actual
configuration or enable operation was run outside test fixtures. Loss of central
exclusion blocks reservation, spawn, transfer and managed dispatch.

The adapter requires the matching core experimental idle-release capability.
Older daemon protocol 268 is incompatible with the new prerequisite transport;
installing this plugin alone does not upgrade or qualify core. No credential,
login, account-generation update, or quota probe is exposed.

## Worker deployment boundary

The worker uses persistent `native-worker.json` with a non-secret `generation`,
`native.lock`, and `native-holder.json` in the plugin host dataDir. The launcher
must be explicitly installed/configured later; build does not install it or
change a provider command. Never replace or unlink the fixed lock inode.

`BB_THREAD_ID` is generated by core's
`packages/agent-runtime/src/thread-shell-environment.ts`; actual native launcher
environment and inherited FD lifetime must still be checked in the authorized
installed-host qualification. Kernel-verified receipts are observations, not a
reservation against unrestricted owner SSH. Unknown descendants retain capacity.
